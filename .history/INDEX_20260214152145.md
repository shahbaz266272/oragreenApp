## 🚀 Getting Started (2 Steps)

### Step 1: Mobile App (30 minutes)

1. Run: `npm install` (dependencies already added to package.json)
2. Create Firebase project at https://console.firebase.google.com/
3. Copy credentials to `.env` file
4. Test with `NotificationDemoScreen.js`

**Documentation:** See `README_NOTIFICATIONS.md`

### Step 2: Backend (20 minutes)

1. Copy 5 files to your existing backend:
   ```bash
   cp notifications.service.js your-backend/services/
   cp notifications.routes.js your-backend/routes/
   cp firebase-admin.js your-backend/config/
   cp logger.js your-backend/utils/
   cp auth.middleware.js your-backend/middleware/
   ```

2. Install dependencies:
   ```bash
   npm install firebase-admin express-rate-limit express-validator axios
   ```

3. Add 3 lines to server.js:
   ```javascript
   import initializeFirebase from './config/firebase-admin.js';
   import notificationRoutes from './routes/notifications.routes.js';
   
   initializeFirebase();
   app.use('/api/notifications', notificationRoutes);
   app.set('User', User);
   ```

4. Configure `.env`:
   ```bash
   cp backend.env.example .env
   # Add Firebase credentials
   ```

5. Add field to User model:
   ```javascript
   pushToken: { type: String, default: null }
   ```

**Documentation:** See `BACKEND_READY.md`

## ✅ Integration Workflow

### 1. User Logs In

```
Mobile App
├─ User enters email/password
├─ App gets Expo/FCM token
└─ Sends to backend with login

Backend
├─ Verifies credentials
├─ Saves pushToken to User record
└─ Returns JWT token
```

### 2. Order Created

```
Backend
├─ Admin/API creates order
├─ Looks up user's pushToken
├─ Sends notification via Expo/FCM
└─ Notification delivered to device

Mobile App
├─ Receives notification
├─ Shows in notification center
├─ User taps notification
└─ App opens to Orders screen
```

### 3. Order Status Updates

```
Backend (via webhook/schedule)
├─ Order status changes to "shipped"
├─ Calls notifyOrderStatus()
├─ Sends notification
└─ Stores timestamp

Mobile App
├─ Receives notification
└─ Can navigate to order details
```

## 📞 Support & Troubleshooting

### If Notifications Aren't Working:

1. **Check Mobile Logs:**
   ```
   Look for: "Expo Push Token: ExponentPushToken[xxxxx]"
   If missing: Check notification permissions
   ```

2. **Check Backend Logs:**
   ```
   Look for: "[INFO] Sending expo notification"
   If error: Check token format, Firebase config
   ```

3. **Check API Response:**
   ```bash
   curl -X POST http://localhost:3000/api/notifications/test \
     -H "Authorization: Bearer TOKEN" \
     -d '{"token":"ExponentPushToken[xxxx]",...}'
   ```

4. **Verify Firebase:**
   - Firebase credentials in `.env`
   - Service account has Messaging permissions
   - Project ID matches

### Common Issues

| Issue | Solution |
|-------|----------|
| "No token found" | Login to save token first |
| Firebase not initialized | Check `.env` file |
| 401 Unauthorized | Check JWT token |
| CORS error | Add URL to `CORS_ORIGIN` in `.env` |
| Rate limit hit | Wait 15 minutes or adjust limits |

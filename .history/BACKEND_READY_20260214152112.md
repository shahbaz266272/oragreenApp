## 🚀 Quick Start (Add to Your Backend)

### 1. Copy 5 Core Files

```bash
# Copy to your backend project
cp notifications.service.js src/services/
cp notifications.routes.js src/routes/
cp firebase-admin.js src/config/
cp logger.js src/utils/
cp auth.middleware.js src/middleware/
```

### 2. Install 1 Dependency

```bash
npm install firebase-admin express-rate-limit express-validator axios
```

### 3. Add 3 Lines to server.js

```javascript
import initializeFirebase from './config/firebase-admin.js';
import notificationRoutes from './routes/notifications.routes.js';

initializeFirebase(); // Initialize first!
app.use('/api/notifications', notificationRoutes);
app.set('User', User); // Your User model
```

### 4. Configure .env

```bash
cp backend.env.example .env
# Add Firebase credentials
```

### 5. Add Field to User Model

```javascript
pushToken: { type: String, default: null }
```

**Done!** You now have 11 notification API endpoints ready to use.

## 💡 Example Usage

### Send Notification

```javascript
import { sendNotification } from './services/notifications.service.js';

const result = await sendNotification(
  'ExponentPushToken[xxxxx]', // or 'FCM:xxxxx'
  'Order Confirmed',
  'Your order #123 is confirmed',
  { data: { orderId: '123', screen: 'Orders' } }
);

// Returns: { success: true, messageId: "..." }
```

### Send to User (Auto lookup)

```javascript
import { sendToUser } from './services/notifications.service.js';
import User from './models/User.js';

const result = await sendToUser(
  userId,
  'Order Shipped',
  'Your order is on the way',
  { userModel: User }
);
```

### Pre-built Function

```javascript
import { notifyOrderPlaced } from './services/notifications.service.js';

// Just call - handles everything
await notifyOrderPlaced(userId, orderId, total, { userModel: User });
```

### Bulk Send

```javascript
import { sendBulkNotifications } from './services/notifications.service.js';

const recipients = users.map(u => ({
  userId: u._id,
  token: u.pushToken
}));

const result = await sendBulkNotifications(
  recipients,
  'Spring Sale',
  '50% off everything',
  { data: { code: 'SPRING50' } }
);

// Returns: { sent: 4523, failed: 12, total: 4535 }
```

## 🔌 Integration Pattern

### 1. On User Login - Save Token

```javascript
if (req.body.pushToken) {
  await User.updateOne({ _id }, { pushToken: req.body.pushToken });
}
```

### 2. On Business Event - Send Notification

```javascript
// After creating order
await notifyOrderPlaced(userId, orderId, total, { userModel: User });

// Or on status update
await notifyOrderStatus(userId, orderId, 'shipped', { userModel: User });
```

### 3. For Bulk - Use Scheduler

```javascript
import schedule from 'node-schedule';

// Run every hour
schedule.scheduleJob('0 * * * *', async () => {
  const result = await sendBulkNotifications(recipients, title, body);
  logger.info('Bulk send complete', result);
});
```
